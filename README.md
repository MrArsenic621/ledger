# Ledger

A personal financial and asset accounting engine built with Python.

## Overview

Ledger is a self-hosted personal financial system focused on modeling transactions, assets, liabilities, historical valuations, and long-term financial state.

## Core Features (Roadmap)

- **v0.1 — Transactions**: Accounts, categories, income, expenses, and transfers.
- **v0.2 — Double-Entry Accounting**: Journal entries, debits/credits balance, accounting invariants.
- **v0.3 — Assets**: Multi-asset tracking and lifecycle management.
- **v0.4 — Liabilities**: Debts, loans, amortization schedules.
- **v0.5 — Historical Valuation**: Point-in-time net worth calculation.
- **v0.6 — External Price Providers**: FX, Gold, Crypto rate sync and caching.
- **v0.7 — Recurring Transactions**: Subscriptions, salary, recurring scheduling.
- **v0.8 — Forecasting**: Forward-looking cash flow projections.
- **v0.9 — Reporting & Export**: Reports and multi-format exports (CSV, XLSX, PDF, JSON).

## Tech Stack

- **Backend**: Python, FastAPI / Django, PostgreSQL, Pydantic, pytest
- **Package Manager**: uv
